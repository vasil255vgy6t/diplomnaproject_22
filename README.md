# PsyStudent Monitor

Сучасна вебсистема для анонімного збору показників психологічного стану студентів під час навчання.

## Можливості
- Анонімне проходження психологічних тестів студентами.
- Автоматичний підрахунок балів і визначення рівня стану.
- Рекомендації після завершення тесту.
- Адмін-авторизація через JWT.
- Dashboard для адміністрації зі статистикою та графіками (Chart.js).
- Фільтрація результатів (дата, тест, рівень стану).
- Керування тестами та адміністраторами.

## Технології
- Frontend: HTML, CSS, JavaScript.
- Backend: Node.js + Express.
- База даних: MySQL.

## Запуск
1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Створіть `.env` на основі `.env.example`.
3. Імпортуйте SQL:
   ```bash
   mysql -u root -p < sql/schema.sql
   mysql -u root -p < sql/seed.sql
   ```
4. Запустіть сервер:
   ```bash
   npm run dev
   ```
5. Відкрийте `http://localhost:3000`.

## Демо-адміністратор
- Логін: `superadmin`
- Email: `admin@psystudent.local`
- Пароль: `password`

## Структура
- `src/server.js` — точка входу.
- `src/controllers` — контролери API.
- `src/routes` — маршрути API.
- `src/public` — фронтенд-сторінки, стилі, скрипти.
- `sql/schema.sql` — структура БД.
- `sql/seed.sql` — тестові дані.
